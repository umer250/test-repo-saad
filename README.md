# Test Repository - Multi-Language Sample Code

This repository contains sample code in various programming languages organized across different branches.

## Branches

- `main` - Main branch with project overview
- `feature/c-programs` - C language examples
- `feature/cpp-programs` - C++ language examples
- `feature/python-programs` - Python language examples
- `feature/java-programs` - Java language examples
- `feature/javascript-programs` - JavaScript language examples

## Purpose

This repository serves as a demonstration of multi-language programming samples and git branch management.
